# 开发计划

日期：2026-10-31。参考对象固定为 `../InkHide_3.0.5.apk`，SHA-256：`1571ee9d7a589df17569dbd61d867c04352144cd3e272a88df23a42bd80e67ac`。

## 目标与不可变约束

做行为可验证、便于维护的同功能微信 Xposed 模块，不是重新签名原 APK，也不是独立聊天客户端。按小版本交付，正确性、隐私和宿主稳定性先于跑分；所有新功能同时评估热路径、内存、启动和生命周期成本，不把性能留到最后补救。

用户指定的交互必须保留：

1. 微信主页搜索栏完整输入 `#hide`，显示设置。
2. 微信「我 → 设置 → 更多 → 关怀模式」，长按「开启」显示同一设置；不改变短按原用途。
3. 多次点击微信首页标题「微信」，或长按标题，切换临时显示和重新隐藏。

两个设置入口复用微信宿主内的原生设置面板、同一个配置库和同一个运行期显隐状态。不把跨进程配置同步伪装成已经实现。独立启动模块 App 只是独立沙箱内的预览/诊断入口。

## 架构与数据流

```text
微信主进程
  ├─ 精确搜索组件 → #hide ──────────┐
  ├─ SettingsCareModeIntro → 长按 ──┴→ 同一 SettingsPanel
  │                                      ↓ 后台解析/持久化
  │                               宿主 MODE_PRIVATE 配置
  │                                      ↓ 一次构建
  ├─ 首页标题多击/长按 → 临显状态 → 不可变可见性快照
  │                                      ↓ 原子替换
  └─ 后续各过滤适配器 ───────────→ 只读规则查询

独立 App → 独立预览（不伪装跨沙箱同步）
```

核心规则与微信混淆类分离。查找、反射、JSON、集合构建、文件读写只在初始化/配置变化等低频路径；高频过滤只读快照。适配器应只注册一次，并在确认目标结构后安装。进程不匹配或结构不匹配则保留宿主行为，而不是用高成本全局钩子兜底。

主进程与推送进程未来通过显式、最小、带调用方校验的通道同步快照版本，不能使用已被系统禁止的 world-readable preferences。配置更新按序执行，持久化失败不能悄悄显示保存成功。生命周期必须撤销监听/回调，不能在静态集合里强引用 Activity。

## 每次开发的性能门槛

1. 先给新增路径分类：每字符/每会话/每帧热路径，或初始化/配置更新冷路径。
2. 正确性测试先通过，再测常见及最坏名单规模；禁止靠漏过滤来换跑分。
3. 热路径不允许文件、网络、JSON、全树/反射扫描、日志拼接、锁等待。
4. 固定输入、预热、多轮、保留校验和；比较同设备同版本前后差异，记录尾延迟和分配。
5. 宿主卡顿、功耗或泄漏退化即阻止该功能默认启用；不把未适配版本假报成已支持。

详见 `PERFORMANCE_zh.md`。极致性能是持续约束，不是未经设备测量即可作出的绝对承诺。

## 真机阶段执行顺序

1. 设备连接后只读确认 Android 版本、ABI、Root/LSPosed 状态和微信 versionCode/versionName；不自动刷机或操作日常账号。
2. 安装自有调试 APK，设置微信作用域，重启目标进程；先验证三个入口/手势与原操作共存。
3. 为一个版本提取/验证 Hook 定位证据，先上会话适配再逐出口扩展；Frida 仅用于必要定位，不作为发布依赖。
4. 用测试账号覆盖收发、返回后台、锁屏、重启、搜索、推送、多账号切换。
5. 同条件采集关闭模块 / 仅入口 / 启用功能的对照；记录 CPU、帧耗时、内存、分配、启动和待机唤醒。
6. 卸载/禁用模块回归微信原行为，演练配置与版本回滚。

## 仓库与交付规则

仓库仅包含自写工程、测试和文档；原 APK、反编译源码、缓存、日志、私钥不入库。用户本次只要求初始化 Git，不自动 commit、不改全局 Git 配置。每次验收区分「已编译」「已单测」「已审阅」「已真机验证」，不得互相替代。

## 官方资料（2026-10-31 读取）

- Android SharedPreferences：`https://developer.android.com/training/data-storage/shared-preferences`，私有存储、apply/commit 及 world-readable 限制。
- Xposed IXposedHookLoadPackage：`https://api.xposed.info/reference/de/robv/android/xposed/IXposedHookLoadPackage.html`，加载回调早于 Application.onCreate，不能假设此时已有可用 Activity。

本工程复用已实际构建通过的固定工具链，不因某个更高版本存在而盲目升级。
